# ALPHA TESTING - ADMIN-SIDE

**System:** Health Kiosk System with IoT Sensors, Data Analytics and Companion Mobile Application
**Test Type:** Alpha Testing (Internal)
**Scope:** Administrator functions
**Pre-Condition:** Login & Registration and User-Side alpha testing completed and cleared.

**Status:** FINALIZED - the question set is closed. Revisions from here on need a new version.

**Tester Name:** ______________________  **Testing Date:** ______________  **Testing Time:** __________

Questions are numbered **Q1-Q74 in final testing order**. Each section of the Alpha Testing keeps its
own numbering, so a question is identified by its section and number together.

The test cases follow the admin sidebar from top to bottom, and every test case begins by
navigating to its module, so the run never jumps between screens without saying so.

> Mark the result for every step performed, and write anything unusual under **Comment**.
> Use **Additional Test / Observation** for anything the predefined steps do not cover.
> A step that was not actually run must be left blank.
