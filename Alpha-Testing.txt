# ALPHA-TESTING
## ALPHA TESTING

**System:** Health Kiosk System with IoT Sensors, Data Analytics and Companion Mobile Application
**Test Type:** Alpha Testing (Internal)
**Environment:** XAMPP · Apache · MySQL · Laravel 12 · PHP 8.2 · React 19 · Supabase · Arduino Sensor Unit

### Alpha Testing Priority

The Alpha Testing of the system shall be conducted systematically to ensure that the major functions
are properly evaluated before proceeding to the succeeding features. The testing follows a prioritized
sequence, beginning with the general authentication functions and gradually progressing to the
user-side features.

**Sequence:** General Login → Forgot Password → Resend Email → User-Side Features

Each priority must be confirmed stable and functional before proceeding to the next. Any defect
discovered during testing shall be documented in the Defects Found table, corrected, and retested
before the succeeding priority is started.

> **How to fill this up:** Perform every step in order and mark ✅ under **Pass** or **Fail**.
> Write anything unusual under **Comment**. Do not tick a row you have not actually run —
> the Pass/Fail columns are the evidence that the test was performed.
